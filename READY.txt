🎯 QUICK PROJECT SUMMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

What is Bepalo Query?
  → Auto-generates REST API endpoints from Drizzle schema + ACL
  → Type-safe access control with role-based rules
  → Eliminates CRUD boilerplate

Core Technologies:
  ✓ TypeScript 5.9.3 (language)
  ✓ Drizzle ORM 0.45.2 (query builder)
  ✓ arktype 2.2.0 (validation)
  ✓ Vitest 3.2.6 (testing)

Main Components:
  ✓ src/query.ts (2,442 lines) - Core engine
  ✓ src/client.ts (~100 lines) - Client types
  ✓ tests/ (~660 lines) - 4 test files

Key Features:
  ✓ Role-based access control (RBAC)
  ✓ Column-level security
  ✓ Row-level security (RLS)
  ✓ Type-safe queries
  ✓ Auto-validation
  ✓ Transaction support
