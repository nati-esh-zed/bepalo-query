1️⃣  cancelRequestBody(req: Request)
    • Safely cancel request body stream
    • Used: 3 times in query.ts
    • Replaced: await _req.body?.cancel().catch(() => {});
    • Savings: ~3 lines

2️⃣  validateAclEntry(aclEntry: any)
    • Check if ACL entry exists
    • Used: 2 times (POST, PATCH methods)
    • Replaced: if (aclEntry == null) checks
    • Savings: ~6 lines

3️⃣  validateTable(tableId: any, schema: any)
    • Check if table exists in schema
    • Prepared for: Future use in GET/DELETE methods
    • Type-safe table validation

4️⃣  getAclRule(aclEntry: any, method: string)
    • Retrieve ACL rule for HTTP method
    • Used: 2 times (POST "POST", PATCH "PATCH")
    • Replaced: aclEntry.control.METHOD lookups
    • Savings: ~10 lines

5️⃣  resolveAclSelector(aclRule, userRole, query)
    • Resolve which ACL selector applies based on role/flags
    • Used: 2 times (POST, PATCH methods)
    • Replaced: 10-line nested ternary operators
    • Savings: ~18 lines
    • Benefit: Major cognitive complexity reduction

6️⃣  applyBodyTransform(body, validateBody, injectBody, ctx, HttpError, status)
    • Apply validation & injection to single or batch bodies
    • Used: 2 times (POST, PATCH methods)
    • Replaced: ~35 lines of duplicate loop logic
    • Savings: ~35 lines
    • Benefit: Largest refactoring win
